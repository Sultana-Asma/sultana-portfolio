07 // Problem Solving

Challenges Faced & Engineering Solutions

Slide 08 / 10

⚙️ Desktop OpenGL on Web

Problem: C++ OpenGL compiles to native .exe, making live browser URLs impossible.

Solution: Built an interactive multi-mode Case Study modal with an HTML5 Canvas simulation mimicking the C++ output.

🎨 Modal Transparency

Problem: Initial modal had background transparency, causing body text to bleed through.

Solution: Implemented a 100% solid dark charcoal slate background (#0c101d) and heavy backdrop blur overlay.

📱 Mobile Viewport Breakages

Problem: 320px–360px screens experienced button squeezing and text overflow.

Solution: Adopted CSS fluid clamp() typography, flex-wrap groups, and High-DPI canvas scaling.
