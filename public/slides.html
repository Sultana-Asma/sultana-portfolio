07 // Problem Solving

Problems I Faced & How I Solved Them

Slide 08 / 10

⚙️ 1. OpenGL Web Problem

The Problem: Our C++ OpenGL graphics project runs on desktop as an .exe file, so it cannot be viewed directly on the web.

My Solution: I designed an interactive Case Study popup with an HTML5 Canvas simulation that recreates Day, Night, and Rain modes in the browser.

🎨 2. Transparent Popup Bug

The Problem: Initially, the popup background was transparent, so the page text behind it was overlapping and hard to read.

My Solution: I added a 100% solid dark charcoal background (#0c101d) and a dark blur overlay so all popup text is clear and readable.

📱 3. Small Mobile Screen Fit

The Problem: On small phones (320px–360px), buttons and text were getting squeezed and overflowing off the screen.

My Solution: I used responsive flex-wrap and CSS clamp() so fonts and buttons resize smoothly on small mobile screens.
